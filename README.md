# Iranian Churn Analysis

A Python project exploring customer churn using the Iranian Churn dataset
from the UCI Machine Learning Repository.

The dataset contains 3,150 customer records. Features summarize the first
nine months; churn labels describe customer status at month 12.

## Planned work

- Explore churn patterns in the data
- Train and evaluate a baseline prediction model
- Later, build a React interface for the model

## Dataset

UCI Machine Learning Repository, [Iranian Churn](https://archive.ics.uci.edu/dataset/563/iranian+churn+dataset).
